# Prime3D

A foundational 3D engine built from first principles, following the "3D Math Primer for Graphics and Game Development".

## Project Structure
- `core-engine/`: The main library containing 3D math and WebGL2 logic.
- `solar-system/`: A standalone 3D simulation powered by Prime3D.
- `examples/`: Minimal visual tests for specific engine features.

## Tech Stack
- **Language:** JavaScript (ES Modules)
- **Graphics:** WebGL2
- **Testing:** Vitest
- **Package Manager:** pnpm
